Hello hello!

To get started you can either go straight to the phyto_ubc_dat.csv file which is the raw data transfered from xml and added id columns.
    You can go ahead and put the "phyto_ubc_dat" file and the "tidy_pump_counts_ubc.xlsx" file into the "phytoncide_collection_ubc_working_file.qmd" if you want to run through the analysis on your own.
Or you can work from the raw xml files and transform them yourself. To do that please put use the data files in the shared OneDrive (download them in the same file organization that they are currently in so the program can sort them correctly) and input them into the "phytoncide_collection_ubc_raw_xmls" file.


If you are just here to see the more extensive report/analysis. You will need to use the "phytoncide_collection_ubc_working_file.qmd" and have it read in bot the "tidy_pumps_counts_ubc.xlsx" and the "phyto_ubc_dat.csv".

Once you have those in there, just make sure all the libraries are working. Set your working directory and then run/render the file into html. If you run into any snags, please feel free to email me!


If you would like to run the data through MetaboAnalyst yourself, just download the "metabo_ubc.csv" file and use that to input into MetaboAnalyst. Detailed instructions for this are found in the "phytoncide_collection_ubc_working_file.qmd"
